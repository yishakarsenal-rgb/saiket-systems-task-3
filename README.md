Simple Navigation Menu — Saiket Systems Task 3

A clean, modern, and responsive navigation menu web application built strictly with pure HTML5 and CSS3. Developed as part of the Saiket Systems Web Development Internship.

Features

- Fixed Navigation Bar:Sticky top header with subtle backdrop blur and dark contrast borders.
- Pure CSS Smooth Scrolling:Native anchor target navigation (`#home`, `#about`, `#services`, `#contact`) utilizing `scroll-behavior: smooth`.
- Pure CSS Mobile Drawer:Responsive off-canvas mobile navigation toggled via CSS checkbox selectors (zero JavaScript required).
- OLED Pitch-Black Design:Modern dark theme architecture with high contrast green accent elements (`#10b981`).
- Semantic HTML Structure:Built following web standards using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags.

Tech Stack

- HTML5:Semantic markup & anchor linking
- CSS3:Flexbox, CSS Grid, Media Queries, CSS Variables, & Checkbox Hack logic
- Deployment:Vercel / GitHub Pages
